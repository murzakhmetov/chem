# Calescence Lab: 3D Изомерия

Интерактивная 3D лаборатория и визуализатор химических молекул и изомерии, созданный с использованием **Three.js**, **Tailwind CSS** и **GSAP**.

## Возможности
- Интерактивное 3D вращение, масштабирование молекул
- Поддержка различных типов изомерии
- Современный интерфейс (Bento Grid)
- Плавные анимации переходов

## Запуск
Просто откройте файл `index.html` в любом современном веб-браузере или включите **GitHub Pages** в настройках репозитория.
